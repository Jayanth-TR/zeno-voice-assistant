# Netcore AI Agents

> **Source and approval note:** Agent descriptions below are taken from
> the supplied Netcore knowledge-base material. Confirm current agent
> names, availability, and capabilities with Netcore before public use.

## 1. Audience Agent

### Purpose

Supports conversational customer-cohort discovery as an alternative to
manually writing SQL queries or configuring segmentation filters.

### How it works

A marketer describes the target audience in natural language. The source
gives this example:

> Find customers who browsed running shoes at least twice in the past 7
> days, added to cart, but did not buy, prioritizing those with an AOV
> above \$100.

The source says the agent parses the intent, evaluates behavioral data,
derives relevant parameters, and builds an addressable cohort.

### Capabilities described in the source

-   Natural-language audience discovery.
-   Behavioral cohort creation.
-   Dynamic evaluation of cohort membership.
-   Identification of high-intent micro-segments.

## 2. Content Agent

### Purpose

Supports generation of brand-aligned, channel-specific marketing
content.

### How it works

It takes a campaign brief and adapts creative assets for supported
channels.

### Capabilities described in the source

-   Email subject lines, preview text, body copy, CTAs, and AMP
    interactive elements.
-   WhatsApp and RCS conversational scripts, rich cards, and quick
    replies.
-   Push and SMS copy.
-   Adaptation to brand voice, character limits, and compliance
    requirements.

## 3. Scheduler Agent

### Purpose

Supports delivery timing and pacing rather than relying only on fixed
batch-and-blast schedules.

### How it works

The source describes the agent as considering user-level timing patterns
and communication fatigue when planning delivery.

### Capabilities described in the source

-   Delivery pacing.
-   Timing based on engagement patterns.
-   Frequency capping across communication channels.
-   Suppression or pacing to reduce message fatigue.

## 4. Insight Agent

### Purpose

Supports campaign and journey analysis through root-cause diagnosis.

### How it works

The source describes the agent as examining journey steps, identifying
performance anomalies, isolating possible causes, and producing
recommendations.

### Capabilities described in the source

-   Identification of deliverability, engagement, and conversion drops.
-   Node-by-node journey diagnosis.
-   Actionable recommendations.
-   Sharing performance learnings with other agent capabilities.

The source includes an illustrative example of a conversion drop at a
journey node. Treat such examples as illustrative, not as a real
customer incident.

## 5. Decisioning Agent

### Purpose

Supports real-time selection of the Next Best Action (NBA) for a
customer profile.

### How it works

The source says it can evaluate signals such as recent behavior,
lifetime value, engagement fatigue, propensity, and product inventory.

### Capabilities described in the source

-   Selecting what message or offer to send.
-   Prioritizing a communication channel.
-   Deciding when communication should be withheld.
-   Helping prevent overlapping campaigns from competing for the same
    customer touchpoint.

## 6. Shopping Agent

### Purpose

Supports conversational commerce on brand digital channels.

### How it works

The source describes the agent as helping shoppers through product
discovery and purchase consideration.

### Capabilities described in the source

-   Answering product questions.
-   Clarifying product sizing and specifications.
-   Recommending relevant catalog items or upsells.
-   Addressing purchase hesitation.
-   Supporting experiences through channels such as WhatsApp, RCS, or
    on-site chat.

## Agent summary

  Agent               Primary role
  ------------------- -------------------------------------------
  Audience Agent      Goal-to-segment and cohort discovery
  Content Agent       Channel-specific creative generation
  Scheduler Agent     Delivery timing and pacing
  Insight Agent       Performance diagnosis and recommendations
  Decisioning Agent   Next Best Action selection
  Shopping Agent      Conversational commerce
