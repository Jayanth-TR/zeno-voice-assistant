## Omnichannel delivery

The source lists the following channels:

### Email and AMP for Email

The source describes: - Email delivery infrastructure. - Interactive AMP
email experiences. - Forms, carousels, and purchase interactions within
supported inbox experiences.

### WhatsApp Business

The source describes: - Automated notification journeys. - Business
branding. - Rich media. - Interactive menus and conversational
experiences.

### RCS

The source describes rich messaging experiences on supported Android
messaging applications, including: - Rich cards and carousels. -
Suggested actions and buttons. - Verified sender experiences.

### SMS

SMS is listed as a supported messaging channel in the supplied material.
Specific capabilities and regional constraints should be confirmed.

### Web personalization

The source describes: - On-site inlays and banners. - Session-triggered
personalization. - Website messaging overlays.

### App push notifications

The source lists app push as part of the delivery stack. Specific
platform support and configuration should be confirmed.

## Netcore MCP Server

### What is MCP?

The source explains Model Context Protocol (MCP) as an open standard
that enables AI applications to interact with external tools and
structured data systems.

### Netcore MCP Server capabilities stated in the source

-   Natural-language analytics queries.
-   Access to cross-channel campaign telemetry.
-   Read-only access and OAuth-based authentication.

The source gives an example query:

> Compare our Black Friday WhatsApp conversion rate with our RCS push
> for the VIP segment.

### Important validation

The source's MCP implementation, supported external clients,
authentication model, data permissions, and available metrics must be
confirmed with current Netcore developer documentation before Zeno
describes them as live capabilities.
